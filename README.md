# Ignite Points Hunter

A single-page app for hunting the most points at Microsoft Ignite 2026: ducks, freebies and the AI Skills Navigator.

- Live scoreboard with ranks and per-lane progress
- Time planner that picks the best points-per-minute quests for the minutes you have
- Add, edit and remove quests; progress saves in the browser
- "Run demo" button to show it off

Point values and locations are starting guesses. Edit the `seed()` list in `index.html` to match the official Ignite 2026 rules.

## Run it

Open `index.html` in a browser. No build step, no dependencies.

Built with Claude in a single prompt.
